# CoreBundle

Bundle de base AkyosCMS pour Symfony. Fournit les helpers communs, la configuration initiale (assets, Twig, sécurité, CKEditor, pagination), les entités/utilitaires partagés et les services mail/SMS.

## Compatibilité

- PHP >= 8.4
- Symfony ^8.0

## Installation

```bash
composer require akyos/core-bundle:^8.0
```
